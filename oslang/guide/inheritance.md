# Inheritance

OSLANG supports class inheritance with overridable behavior.

## Concepts
- A class can extend a base class (syntax per version spec).
- **`VIRTUAL`** members can be overridden; **`OVERRIDE`** provides specialized behavior in derived classes.
- **`BASE`** accesses base-class members; **`ME`** refers to the current instance.
