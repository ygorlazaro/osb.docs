# Events

OSLANG includes event-driven constructs for declaring, handling, and raising events.

## Concepts
- **`EVENT`** — declare an event.
- **`ON`** — register/handle an event.
- **`RAISE`** — emit/trigger an event.

Exact syntax, payloads, and scoping are defined by the language specification.
