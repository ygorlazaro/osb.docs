# Interfaces

Interfaces define contracts that classes can implement, enabling polymorphic behavior.

## Concepts
- Declared with `INTERFACE ... END` (per spec).
- Classes implement interfaces and provide required members.
- Used with object-oriented designs alongside [classes](classes-and-objects.md) and [inheritance](inheritance.md).
