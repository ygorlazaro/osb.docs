# Spec versions

Versioned OSLANG specifications are maintained in the `osb.oslang` repository as `OSLANG-*-SPEC.md` (and related notes).

## Mirroring policy
- Prefer linking to the canonical spec files in `osb.oslang` to avoid drift.
- If snapshots are added here, name them clearly by version and record the source commit/date.
- Treat `OSLANG-GAP.md` as a companion document for known gaps.

## Available source specs (reference)
`OSLANG 0.1 — Especificação da Linguagem.md`, `OSLANG-0.2-SPEC.md` … `OSLANG-0.73-SPEC.md`, `OSLANG-SPEC.md`, `OSLANG-GAP.md` under `osb.oslang/`.

See [Changelog](../changelog.md) for a summary.
