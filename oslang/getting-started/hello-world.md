# Hello World

A minimal OSLANG program that prints a message:

```osl
FUNCTION MAIN()
    PRINT "Hello, World!"
END FUNCTION
```

## Notes
- `FUNCTION MAIN()` is the conventional entry point.
- `PRINT` writes output to the host console.
- OSLANG syntax and available APIs depend on the language version in use; see the [specification](../specification/README.md) and [reference](../reference/README.md).
