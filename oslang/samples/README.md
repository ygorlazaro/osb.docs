# OSLANG samples

Sample programs live in `osb.oslang/samples/` (e.g. multi-file examples) and throughout OSB sources where OSLANG is used.

## Notable examples (source)
- **Multi-file:** `osb.oslang/samples/03-MultiFile/` (e.g. `Main.osl`, `Person.osl`, `Math.osl`) demonstrating `USING`, modules, and language features.
- **Language/extension docs:** examples referenced in `osb.oslang/docs/oslang/` and `oslang.vscode/README.md`.

## Usage
Run samples with the OSLANG interpreter/host appropriate to your environment and language version. Feature availability depends on the targeted spec version.

> Source: `osb.oslang/samples/`.
