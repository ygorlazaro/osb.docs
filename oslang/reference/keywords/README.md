# Keywords

OSLANG reserves keywords for declarations, control flow, types, and runtime operations. The exact set depends on language version.

## Representative keywords
- **Control flow:** `IF`, `ELIF`, `ELSE`, `END`, `FOR`, `TO`, `STEP`, `WHILE`, `DO`, `SWITCH`, `CASE`, `DEFAULT`, `BREAK`, `CONTINUE`, `RETURN`
- **Declarations:** `FUNCTION`, `CLASS`, `INTERFACE`, `CONSTRUCTOR`, `VAR`, `GLOBAL`, `USING`, `EVENT`, `ENUM`
- **OOP/modifiers:** `NEW`, `ME`, `BASE`, `VIRTUAL`, `OVERRIDE`, `PUBLIC`, `PRIVATE`, `PROTECTED`, `STATIC` (as applicable)
- **Logic/values:** `AND`, `OR`, `NOT`, `TRUE`, `FALSE`, `NULL`
- **Errors/events:** `TRY`, `CATCH`, `RAISE`, `ON`
- **I/O & misc:** `PRINT`, `INPUT`, and version-specific keywords (`TYPEOF`, `SHOW`, etc.)
