# Built-in functions

OSLANG provides built-in functions and helpers for math, strings, arrays, conversion, and host integration. Availability is version- and host-dependent.

## Representative built-ins
- **Math:** `ABS`, `SQRT`, `POW`, `FLOOR`, `CEIL`, trig and related functions in newer versions
- **Conversion/inspection:** `STR`, `NUMBER`, `BOOL`, `TYPEOF` (version-dependent)
- **Collections/strings:** `COUNT` and other helpers via namespaces/methods in later specs
- **I/O:** `PRINT`, `INPUT` (language keywords/forms with runtime behavior)

## Full per-function pages
Detailed pages (one per built-in) are maintained in `osb.oslang/docs/oslang/reference/built-ins/` in the `osb.oslang` repository.
