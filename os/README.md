# OS modules

Documentation for OSB operating-system components. Status reflects the current state of each module and may change as development progresses.

## Modules
- [Core](core/README.md) — `osb.core`: shared freestanding runtime (`MiniCoreLib`)
- [Kernel](kernel/README.md) — `osb.kernel`: bootable kernel, subsystems, and roadmap
- [Userspace toolkit (osbkt)](osbkt/README.md) — syscall wrappers, CRT/startup, ABI
- [Shell](shell/README.md) — `osb.shell`: userspace shell and migration from legacy
- [Toolkit](toolkit/README.md) — `osb.toolkit`: GUI primitives for freestanding apps
- [XWin](xwin/README.md) — `osb.xwin`: graphical window manager
